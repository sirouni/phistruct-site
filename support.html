Getting started

Building something

Tap the white ball to see every direction a strut can go from it. Tap one of the glowing holes to place a strut of the currently selected color and length. Keep going from any ball in your build.

Colors & lengths

Tap the color and length controls in the toolbar to set what the next strut you place will look like — blue, red, yellow, green, or teal (half-green); lengths short, medium, and long.

Model Library

Tap Library on the dock to browse 134 built-in models, grouped by shape family and difficulty. Open one for a step-by-step guided build (use ‹ › to step, or Complete), or toggle a translucent reference ghost and build freely alongside it.

AR

On iPhone and iPad, use the cube-in-brackets control to place the current build on a real table at room scale. Walk around it, then return to the canvas to keep building or export. The Mac app does not include AR or use the camera.

Mac

The same $14.99 purchase includes a native Mac app. Click where you'd tap. Use File, Edit, Build, Window, and Help in the menu bar. Drop a .vZome or PhiStruct .json project onto the window to open it. The interface follows the Mac's language for the twelve languages (Arabic and Hebrew are right-to-left in the builder; macOS menus stay left-to-right).

Saving & exporting

From ⋯ (File): Save / Open keep an exact .json project file you can reopen later. Export gives you a high-resolution PNG, a full-color GLB (for Blender/AR/web viewers), a centered STL for 3D printing, or a .vZome file for desktop vZome — plus a parts list (color × length × count) you can copy to buy or sort real struts. On iPhone, Save and Export use the system share sheet. On Mac, they use the standard save and export panels.

Why can't I place a strut somewhere?

PhiStruct only lets you place struts that would be physically buildable — a strut is never allowed to pass through another strut. If a direction isn't glowing, that placement would cause a collision.

Report a bug or request a feature

Open a new GitHub issue with your device model and iOS or macOS version, and what you were doing when it happened. Screenshots or screen recordings help a lot. You can also browse existing issues.
